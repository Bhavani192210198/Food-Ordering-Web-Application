# \# Food Ordering Web Application

# 

# A Java-based web application for an online food ordering experience.

# 

# \## Technologies Used

# 

# \- Java

# \- Java Servlets

# \- JSP (JavaServer Pages)

# \- JDBC

# \- MySQL

# \- HTML, CSS and JavaScript

# \- Apache Tomcat 10

# 

# \## Project Features

# 

# \- Restaurant listing

# \- Restaurant and food browsing

# \- Food ordering workflow

# \- Cart and checkout

# \- Database integration

# 

# \## Prerequisites

# 

# \- JDK 21

# \- Apache Tomcat 10.1

# \- MySQL Server

# \- Eclipse IDE (or another Java IDE)

# \- MySQL JDBC Connector

# 

# \## Database Configuration

# 

# 1\. Create a MySQL database named `foodapp`.

# 2\. Import the SQL script provided in this repository.

# 3\. Copy `src/main/java/db.properties.example` to `src/main/java/db.properties`.

# 4\. Update the database username and password in `db.properties`.

# 5\. Keep `db.properties` private. It is excluded from Git tracking.

# 

# Example configuration:

# 

# ```properties

# FOODAPP\_DB\_URL=jdbc:mysql://localhost:3306/foodapp?useSSL=false\&serverTimezone=UTC

# FOODAPP\_DB\_USER=root

# FOODAPP\_DB\_PASSWORD=YOUR\_LOCAL\_MYSQL\_PASSWORD

# ```

# 

# \## How to Run

# 

# 1\. Import the project into Eclipse as an existing project.

# 2\. Configure Apache Tomcat 10.1.

# 3\. Configure the MySQL database.

# 4\. Start the Tomcat server.

# 5\. Open the application in your browser using its deployed context path.
